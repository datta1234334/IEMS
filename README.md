# Student IEMS System

## Overview
A complete Student Integrated Education Management System built with Python and JSON storage.

## Features
- **Role-based access control** (Student, Teacher, Staff)
- **Secure authentication** with SHA-256 password hashing
- **JSON-based data storage** (no database server required)
- **Modular architecture** for easy maintenance
